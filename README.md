# tictactoe-with-backtracking

Uppgiftsbeskrivning: 

Skriv ett program som spelar Luffarschack (Tic Tac Toe) med användning av backtracking-metoden så som den presenteras i kursmaterialet. Spelet skall använda sig av ett 3*3 spelbräde. Spelaren (alltså människan som använder programmet) börjar med sitt drag, efter vilket datorn automatiskt gör sitt motdrag enligt den optimala spelstrategin. Det skall inte behövas något klick på spelbrädet för datorns drag, utan responsen på människans drag skall göras helt automatiskt. Spelet skall avslutas när den ena spelaren har vunnit eller när brädet är fullt och spelet alltså blir oavgjort. 

Du kan utgå från den bifogade koden i filen LS.java, som implementerar ett enkelt användar­gränssnitt för luffarschack. Det är fritt fram att modifiera koden, bara man implementerar ett grafiskt gränssnitt och följer den metod baserad på backtracking som presenterats i kursen.

Testa din lösning noggrant. I en korrekt implementation skall det inte gå att besegra datorn, eftersom den spelar optimalt i varje drag. Det bästa resultatet den mänskliga spelaren kan nå är oavgjort.
